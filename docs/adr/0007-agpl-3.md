# 0007 — Licence AGPL-3.0

- **Stav:** Přijato
- **Datum:** 2026-08-18
- **Kontext fáze:** F0

## Kontext

Produkt jde ven jako open source a zároveň běží jako placená cloudová služba. Chceme, aby
si ho firmy mohly self-hostovat a auditovat (to je součást bezpečnostního příběhu — „vaše
klíče neopustí vaši infrastrukturu“), ale nechceme, aby ho někdo provozoval jako uzavřenou
SaaS kopii bez sdílení úprav.

## Rozhodnutí

**GNU AGPL-3.0** pro celý kód repozitáře. Komerční licence na vyžádání (otevírá dveře
open-core modelu, aniž bychom ho teď stavěli).

## Důsledky

- Provozovatel modifikované verze jako síťové služby musí zpřístupnit zdrojáky svých úprav.
- Část firem má AGPL na interní blacklistu — proto je v README potřeba explicitně říct, že
  **licence se týká kódu, ne dat klientů**, a že běžný self-host bez úprav nic nepublikuje.
- Přispěvatelé přispívají pod AGPL; CLA zatím nezavádíme (bariéra vstupu), což ale znamená,
  že pozdější změna licence by vyžadovala souhlas přispěvatelů.
- Závislosti musí být AGPL-kompatibilní — licence check patří do CI (backlog F5).
